----------------------

These font families are available through Google Fonts and their upstream
font projects. Google Fonts states that each family directory contains
the appropriate license file and that font files contain licensing and
authorship metadata.

Source:

Google Fonts documentation:
https://googlefonts.github.io/gf-guide/metadata.html

Important
---------

1. This file does NOT replace the original license text of any font.
2. If an upstream license file (for example OFL.txt or LICENSE.txt) is
   available for a font family, keep that license file with the font or
   include it in the project's fonts/licenses directory.
3. Do not remove or alter copyright, trademark, Reserved Font Name, or
   other attribution information contained in the original font files.
4. The subtitle project's own source code may be distributed under a
   separate open-source license. That license does not change the
   licensing terms of these third-party fonts.
5. If a font file is replaced with a different version or obtained from
   a source other than Google Fonts, its upstream license and attribution
   should be checked again before redistribution.

Reserved Font Names
-------------------

Some SIL OFL fonts may contain a Reserved Font Name requirement. This is
relevant if the font itself is modified or renamed. The bundled font
files in this project are intended to be distributed unchanged.
